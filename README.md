# Dad's Birthday Website

A 10-page, responsive birthday website in a black-and-gold theme, with English and Burmese text.

## Run it
1. Extract the ZIP.
2. Open the `Dad_Birthday_Website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Navigate using the top menu and each page's next button.

## Files
- 10 separate HTML pages
- `css/style.css` — shared visual design
- `css/responsive.css` — mobile/tablet layouts
- `js/main.js` — gift, letter, memory, wish-card, candle and confetti interactions

## Personalize it
- Edit the English and Burmese text directly in each HTML page.
- Replace emoji illustrations with your own SVG/PNG artwork if desired.
- Google Fonts are loaded online; system fallbacks are used if offline.
- No external images or music files are required.

Note: The website uses emoji/illustration-style artwork rather than personal photos, as requested.
